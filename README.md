# MING FIT

> 今天也比昨天强一点。

私人健身训练工作台。

## 功能

- **力量训练** — 结构化训练计划，组数/次数/重量记录
- **有氧训练** — 有氧与消耗记录
- **恢复计划** — 主动恢复 / 完全恢复
- **训练数据记录** — 训练历史、重量记录、TODAY REVIEW
- **MING PLAN / SMART PLAN** — 个性化训练计划选择
- **每日推送（DAILY PUSH）** 与 **YAN MODE** 陪伴式激励

## 技术

- 纯前端静态应用（HTML / CSS / JavaScript）
- 无后端、无数据库，所有数据保存在浏览器本地（localStorage）
- 支持手机竖屏使用，数据刷新/重开不丢失

## 使用

打开在线地址即可使用，首次进入请完成「认识一下明哥」建档流程。

数据仅保存在当前浏览器设备，不上传任何服务器。
